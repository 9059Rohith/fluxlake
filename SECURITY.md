# Security model

Operational reads and writes are authenticated by default: transactions, gold, schema, pipeline details, metrics, quarantine and OpenAPI require a bearer token. Missing, whitespace-only, shorter-than-32-byte, oversized or invalid token configuration disables protected routes with 503; invalid credentials return 401. Credentials are compared as bytes in constant time. Never put tokens or database URLs in query strings, frontend code or source control.

Optional public mode requires explicit exact hostnames and exposes only a synthetic aggregate view. A public row must carry boolean `data.synthetic=true`; unmarked/private records are excluded. IDs and arbitrary attributes are never serialized into the public summary. The dashboard uses actual Parquet/SQL results and states the capture/freshness profile honestly. The request profile replays a bounded read-only snapshot of retained PostgreSQL outbox history; it is request-triggered, not a continuously running pipeline. See [hosting.md](docs/hosting.md).

Authorization is checked before parsing event bodies. HTTP bodies are capped at 2 MB, nesting at 32 levels, structural nodes at 20,000, strings at 4096 UTF-8 bytes, event records at 64 KiB and batches at 1000. Transaction/quarantine reads default to 100 rows and cap at 500 with bounded offsets; Parquet reads stream bounded batches. Event attributes cap at 32 and the persisted schema at 256 to prevent widening-state exhaustion. All strings must encode as strict UTF-8; malformed surrogates quarantine before state commit. Synthetic markers must be actual booleans. Limits apply before state mutation; accepted invalid domain records retain raw/quarantine evidence.

Responses set no-store, nosniff, no-referrer, frame denial, restrictive same-origin CSP and disabled camera/microphone/geolocation permissions. Dashboard scripts/styles are fixed same-origin assets, with no inline-script exception. Exact Host allowlists prevent arbitrary host headers. HTTPS responses set HSTS. Uvicorn defaults to 32 concurrent requests, backlog 64, five-second keepalive and no server-version header. Public summary work is cached under a lock for five seconds. Hosting ingress must provide TLS, connection/request timeouts and rate limits; these app bounds are not an Internet-scale denial-of-service guarantee.

The private source connection is never rendered or logged. Request replay uses PostgreSQL read-only repeatable-read transactions, bounded source history and connection/query timeouts; failure returns a generic 503 without credentials or database exception strings. It never modifies source acknowledgements. A source-only SELECT identity is sufficient for request mode. `sql/relay-role.sql` supplies an administrator-applied NOLOGIN capability role with SELECT and processed_at-only UPDATE for the polling relay; a real PostgreSQL regression proves event-body/source deletion is denied. Migration and seeding identities remain separate and private. Development Compose retains its local owner account for source setup; do not reuse that owner identity as a public-host runtime credential.

Containers use a digest-pinned minimal runtime, UID 10001, a writable data directory, and read-only root/capability restrictions in Compose. Runtime build tools are removed. Dependency and image audit evidence is recorded with explicit scope and date; no clean-scan claim covers an untested provider runtime or future vulnerabilities. Keep lake volumes private and encrypt the host disk. SQLite, bronze and Parquet contain transaction data; back up the complete stopped volume in polling mode.

Managed S3 blocks public access, uses encryption/versioning and denies non-TLS requests. Kinesis is encrypted; private DMS source endpoints reference Secrets Manager. Organizational IAM, network, CA, remote-state and retention policies remain deployment prerequisites. Report vulnerabilities privately without including transaction data or credentials; rotate exposed credentials immediately.

The [verified public release](docs/public-deployment.md) uses a dedicated isolated non-superuser PostgreSQL role with cross-project CONNECT denied. Its DSN enforces `sslmode=verify-full`, `sslrootcert=/etc/ssl/certs/ca-certificates.crt` and `channel_binding=require`; credential values are private. Role-level statement/lock/idle-in-transaction defaults are 15/10/30 seconds. Replay further applies 5-second connect/statement and 2-second lock limits. Public verification confirmed protected operational reads 401, authorized reads 200 and instance-local fixture writes 403.
