Hover feedback belongs to controls and artwork. The reduced-motion rule removes the entrance, depth, progress and hover movement. The system uses native scrolling and the existing dependencies.

## Design comparison

The comparison uses the original composite concept, the loaded in-app browser desktop capture and the loaded mobile Lighthouse capture. Each runtime data claim comes from the retained public evidence or the separately labeled archive report. [Original concept](../evidence/design/field-atlas-concept.png)

| Comparison | Concept evidence | Render decision |
|---|---|---|
| Headline and action | Follow the event, with a mint Replay audit action | Preserved the headline and primary CTA. The secondary Explore events action opens the actual Silver explorer. |
| Signature image | Violet terraced cliffs with a luminous path leading to the dome | Created a dedicated image with the optical dome on the right and a calm text region on the left. The narrow hero uses a responsive encoding and crop. |
| Layout | Hero separated from a functioning tool surface | Embedded the hero in the existing sidebar shell and placed the live metrics immediately below. The sidebar retains the actual fourteen routes. |
| Workflow chapters | Image-backed feature stories lead to a deeper action | Used six distinct illustration compositions linked to real source, bronze, silver, drift, replay and analyst routes. |
| Evidence, density and type | Compact tool chrome, authored heading and readable tables | Kept the original evidence table, command search and drawer semantics. Inter and monospace identifiers establish the hierarchy. |
| Color and motion | Aubergine, lilac and mint with directional light | Applied the palette to navigation, charts, controls and surfaces. Subtle movement emphasizes the art, with static layout under reduced motion. |

The board’s illustrative pipeline and event names were replaced by actual source and route names. The desktop and mobile shells retain the original navigation and controls, including refresh, command search and operator access.
