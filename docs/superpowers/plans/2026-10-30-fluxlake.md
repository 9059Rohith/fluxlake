# FluxLake implementation plan — 2026-10-30

User authorized autonomous implementation and verification. Local profile is PostgreSQL transactional outbox, explicitly not WAL capture. Managed alternative uses DMS WAL CDC → Kinesis → Glue PySpark Iceberg → Athena. No cloud provisioning is represented as completed.

1. Write behavioral tests for insert/update/delete, replay, stale revisions, event collisions, recovery, additive attributes, quarantine, SQL aggregates, authenticated API and actual PostgreSQL commit/rollback behavior.
2. Observe initial failures, implement durable state plus immutable bronze and atomic Parquet snapshots, then PostgreSQL trigger/worker and API.
3. Add Docker Compose, benchmark, managed AWS Terraform and executable PySpark job.
4. Run full tests, lint, dependency audit, Docker integration if daemon becomes available. Record exact evidence and limitations; commit only this repository.

Decisions: integer minor-unit money; durable tombstones; source per-key revisions; source acknowledgements by row, never MAX(id) high-water mark; all local writers serialize through a process lock. Exactly-once resulting state over at-least-once delivery, no distributed exactly-once claim. Snapshot-per-batch local implementation favors correctness at small scale; Iceberg managed profile handles larger workloads.
